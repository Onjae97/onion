# 로그인 기능 Spec (연습용 샘플)

## 1. 로그인

- 사용자는 아이디와 비밀번호를 입력하고 [로그인] 버튼을 눌러 로그인한다.
- 아이디는 4~20자의 영문 소문자와 숫자로 이루어진다.
- 비밀번호는 8~16자이며 영문, 숫자, 특수문자를 각각 1자 이상 포함해야 한다.
- 로그인에 성공하면 메인 화면으로 이동하고, 상단에 "OOO님 환영합니다" 문구가 표시된다.
- 아이디 또는 비밀번호가 틀리면 "아이디 또는 비밀번호가 일치하지 않습니다." 메시지가 표시된다.
- 아이디나 비밀번호 칸이 비어 있으면 [로그인] 버튼이 비활성화된다.

## 2. 로그인 실패 잠금

- 비밀번호를 연속 5회 틀리면 계정이 30분 동안 잠긴다.
- 잠긴 계정으로 로그인하면 "계정이 잠겼습니다. 30분 후 다시 시도해 주세요." 메시지가 표시된다.
- 로그인에 성공하면 실패 횟수는 0으로 초기화된다.

## 3. 자동 로그인

- 로그인 화면에 [자동 로그인] 체크박스가 있다. 기본값은 해제 상태이다.
- 체크하고 로그인하면 앱을 다시 실행했을 때 로그인 화면 없이 메인 화면이 표시된다.
- 로그아웃하면 자동 로그인이 해제된다.
